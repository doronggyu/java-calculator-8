# java-calculator-precourse

## 요구사항 분석
1. 기본 구분자 처리
- 입력 문자열에 포함된 숫자들은 기본 구분자인 "," 또는 ":" 로 구분된다.
- 해당 구분자들을 기준으로 문자열을 분리한 후 각 숫자를 정수로 변환하여 모두 합산한 겨로가를 반환한다.

2. 커스텀 구분자 처리
- 입력 문자열이 "//"로 시작하면 커스텀 구분자 형식이다.
- "//"와 "\n" 사이에 위치한 문자를 커스텀 구분자로 지정한다.
- 커스텀 구분자를 기준으로 숫자를 분리하여 합산 결과를 반환한다.

3. 예외처리
- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생 시킨 후 애플리케이션은 종료되어야 한다.

## 로직 설계
1. 입력문자열이 //로 시작하는지 판별
2. 해당되면 커스텀 구분자 추가, 아니면 기본 구문자만 사용
3. 구분자로 문자열을 분리한 후 합산해서 반환
4. 예외처리
